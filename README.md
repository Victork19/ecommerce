# Shoply

A small React e-commerce assessment app with a static product catalog, cart, and demo checkout flow.

## Live demo

[Open the deployed Shoply app](https://shoplyy.pages.dev/)

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite. Do not open `index.html` directly in the browser.

## Usage

1. Browse the products and add items to the cart.
2. Open the cart to change quantities or remove items.
3. Continue to checkout and complete the required customer fields.
4. Submit the demo order to view the confirmation screen.

## Technology

- React
- Vite
- React Context and local component state
- Static product data

No backend, Redux, authentication, or real payment gateway is included.
