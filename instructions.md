Practical Coding Assessment – E-Commerce Platform

Duration: 1 Hour

IMPORTANT

* You are required to share your screen for the entire duration of the 1-hour assessment.
* Your screen must remain visible throughout the assessment.
* You are expected to work independently and demonstrate your coding and problem-solving process.

TASK

Build a simple E-Commerce Platform using your preferred development tools and technologies.

The application should allow users to:

1. View Products

* Display a list of available products.
* Each product should have relevant information such as name, image, price, and description.

2. Add Products

* Users should be able to add products to their shopping cart.
* Users should be able to view the products they have added to the cart.

3. Shopping Cart

* Display selected products in the cart.
* Show the quantity and total price.
* Users should be able to remove products from the cart.

4. Checkout

* Create a simple checkout page/process.
* Display the order summary and total amount.
* Include basic customer/order information fields.
* A real payment gateway is not required. Focus on demonstrating the checkout flow.
